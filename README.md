## Como mexer no código

como o normal tu inicia fazendo ´npm install` e para testar é só fazer ´npm start`.
para buildar:

- ´npm run build:win`: cria o executável e o instalador para Windows.
- ´npm run build:lin`: cria o executável e o instalador para Linux.
- ´npm run build:mac`: cria o executável e o instalador para MacOS.
